# Business Rules

## Currency Rules
1. **Dynamic Currency**: The application must support dynamic currency selection via `CurrencyProvider`.
2. **Formatting**: All monetary values must be formatted using the selected currency symbol and 2 decimal places.
3. **Persistence**: The selected currency must be persisted across app restarts.
4. **Reports & Receipts**: All generated PDFs and shared messages (WhatsApp) must use the currently selected currency symbol.ded in the selected currency. (Phase 2)
